CONTACT FORM
------------
The quote form uses FormSubmit and sends to:
info@valutints.co.uk

IMPORTANT:
On the FIRST real submission, FormSubmit may send an activation email to
info@valutints.co.uk. Open that email and confirm the address once.

The form:
- does not open the visitor's email app
- does not require PHP
- submits in the background
- shows success/failure feedback on the same page

LOCAL TESTING
-------------
Because the finished site no longer requires PHP, you can preview it with a simple local
web server. If Python is installed:

  python -m http.server 8080

Then open:
  http://localhost:8080/

The form itself requires internet access because FormSubmit is an external service.
